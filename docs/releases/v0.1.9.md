# Gather v0.1.9

This release improves data integrity, backup reliability and desktop behavior while
keeping Gather offline by default. The app and its PostgreSQL database run on your
machine. AI remains optional and uses your explicitly configured local Ollama model.

## What changed

- Removed sources can no longer feed delayed extraction, photo or embedding results.
  Remembered source history also prevents unsupported restoration after deletion.
- Corrections retain the complete previous claim and its relationships, withdraw
  dependent conclusions, and rebuild or clear stale structure.
- Recurring statements preserve separate temporal episodes when a conflicting
  state intervenes, including before the scanner runs.
- Exports use a consistent database snapshot. Large bundles stream with bounded
  memory; imports enforce size limits and roll back atomically on failure.
- Backup retention groups Gather snapshots correctly across changing export filenames.
- Local embeddings retry outages and pending work, reject delayed stale responses,
  and rebuild incompatible vectors when the configured model changes. Text search
  stays available.
- Browser-origin checks protect mutating local API requests.
- A second desktop launch restores and focuses the existing window without taking
  ownership of its services. Windows foreground handoff and macOS Finder/Dock
  reopening are handled explicitly; crash recovery retains service ownership.
- Library uploads refresh the selected detail while retaining selection and loaded
  pagination depth. Stale list successes and errors are ignored.
- Similar-project caches invalidate on committed semantic changes, even when row
  counts do not change.
- Updated dependencies, including Tauri 2.12 and dialog 2.8, and adapted Word
  extraction to quick-xml 0.42 with additional text/encoding regressions.

## Upgrading

Keep a **local export before upgrading**. Startup applies migrations 0020–0024,
which preserve claim revisions, temporal episodes and source history. Existing
vectors without a known model identity are cleared and rebuilt using your
configured local model; no model is downloaded automatically.

To return to an older release, restore the pre-upgrade export using that older
application. Do not attempt to roll the new database schema back in place.

The v1 export/import bundle format remains supported. See the
[backup runbook](https://github.com/joeydd032995-pixel/Gather/blob/v0.1.9/docs/BACKUP-RUNBOOK.md)
for bundle limits and temporary disk requirements.

## Downloads and verification

Choose the installer for your operating system from this release's assets.
The desktop installers include the app, daemon, PostgreSQL and pgvector.
Standalone daemon archives are also provided. Verify downloads against the
attached `SHA256SUMS` file.

Signing and in-app update availability depend on the repository's configured
signing keys. See the
[installation guide](https://github.com/joeydd032995-pixel/Gather/blob/v0.1.9/docs/INSTALL.md)
for first-launch instructions.
