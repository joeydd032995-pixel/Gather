# Gather v0.1.11

A follow-up to v0.1.10, from using it on real projects. Everything still runs on your
machine.

## What changed

- **A new "What Gather found" view under Explore.** It lists every statement Gather has
  learned across all your files, newest first. Filter by words or by kind (facts, claims,
  decisions, preferences, events), see which file each came from (click to open it in the
  Library), and page through the rest with Show more.
- **Code-comment banners are no longer treated as names.** A line like
  `// — Fixture shape —` from a source file could become an entity and then a "same
  thing?" suggestion. Names must now start and end on a letter or digit, so those are left
  out, while names such as `C++`, `.NET` and `Canon EF 70–200mm` are kept.
- **Quotes, bold and trailing ellipses no longer cost a whole statement.** "I use
  "PostgreSQL" for storage", "I use **PostgreSQL**" and "I use PostgreSQL…" now keep their
  fact, with the name cleaned up.
