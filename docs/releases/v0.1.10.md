# Gather v0.1.10

Gather now learns less, and what it keeps is worth reading. Everything still runs on your
machine; the optional local Ollama model is used only if you configured one.

## What changed

- **Quality gate on what Gather learns.** Arithmetic and code lines, questions, sentence
  fragments, and filler or fragment-shaped entity names are no longer kept. Prose that sits
  next to code in the same file is still read.
- **Fewer items to review.** The review tray holds at most 25 low-confidence or
  uncertain-modality items at a time (the most informative first); an existing oversized
  tray is trimmed on the next pass. Entity names are cut at the clause ("the database for
  the billing service" becomes "the database").
- **Document summaries.** Each document gets a summary: its main topics, the sentences that
  say the most, and an outline. It is built offline; a local model, if configured, may reword
  it, and the wording is kept only if it stays grounded in the document. It shows as a
  **Summary** panel in the Library.
- Summaries for existing documents appear after the background worker next runs.
